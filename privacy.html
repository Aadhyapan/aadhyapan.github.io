Privacy Policy

Last updated: November 11, 2026

This policy covers the website at aadhyapan.github.io and the GitHub repositories in the Aadhyapan organization. It does not describe how the Android app itself handles data.

What we collect

Nothing. This website has no accounts, forms, comments, cookies, analytics, advertising, or tracking scripts. We do not ask for or store your name, email, or any other personal information.

Hosting

The site is hosted on GitHub Pages. GitHub, as the host, may process technical data such as your IP address and browser details when you visit, as described in the GitHub Privacy Statement. We do not receive or control that data.

Downloads

The APK file is served from the same GitHub-hosted repository. Downloading it is subject to GitHub’s own logging and policies.

Fonts and third-party resources

The site uses only your device’s system fonts and a local stylesheet. It loads no third-party scripts, fonts, or trackers.

Public contributions

If you open an issue, discussion, or pull request on GitHub, that content and your GitHub username are public and handled by GitHub. Please do not post private or sensitive information there.

External links

This site links to other websites, including GitHub and ramanchapagain.github.io. We are not responsible for their content or privacy practices.

Children

This site does not knowingly collect information from anyone, including children.

Changes

We may update this policy. The date above shows the latest revision.
